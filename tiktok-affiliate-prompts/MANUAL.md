## 2. เริ่มใช้งาน 5 นาที / 5-minute quick start

1. **เปิดแชทใหม่ใน AI** → วาง **SYSTEM PROMPT** จาก `00_master-template.md` เป็น system message (ครั้งเดียวต่อแชท)
   Open a fresh AI chat → paste the **SYSTEM PROMPT** as the system message (once per chat).
2. **เลือกชุด** 1 อันจาก `index.csv` (หรือ dropdown ใน `prompts-599.csv`) → เปิดไฟล์หมวดนั้นใน `prompts/`
   Pick one set from `index.csv` → open its niche file in `prompts/`.
3. **คัดลอก PROMPT (TH หรือ EN)** ของชุดนั้น → เติมตัวแปรใน `[...]` ให้ครบ
   Copy that set's **PROMPT (TH or EN)** → fill every `[...]` variable.
4. **วางเป็น user message แล้วส่ง** → ได้คำตอบครบ 8 ส่วน
   Paste as the user message → get the 8-section answer.
5. **ตรวจข้อ 8 (⚠️ Compliance check)** ให้ครบก่อนถ่าย/โพสต์ → เปิด Commercial Content Disclosure ในแอป
   Complete section 8 before filming/posting → turn on in-app disclosure.

> 💡 เคล็ดลับ: 1 แชท = 1 สินค้า/1 ชุด ถ้าอยากได้หลายมุม ให้เปิดแชทใหม่หรือรันชุดถัดไปในแชทเดิมได้เลย
> 💡 Tip: 1 chat = 1 product/set. New sets can run in the same chat after the system prompt is set.

## 3. วิธีใช้ทีละขั้น / Step-by-step

### ขั้นที่ 1 · ตั้ง SYSTEM PROMPT (ทำครั้งเดียว)
- เปิด `00_master-template.md` → คัดลอกบล็อกใต้หัวข้อ **SYSTEM PROMPT (TH + EN)**
- วางเป็น **system message** (ChatGPT: ตั้ง Custom Instructions/Project · Claude: Project instructions · แชททั่วไป: วางเป็นข้อความแรกแล้วเว้นวรรค)
- SYSTEM PROMPT กำหนดบทบาท, ภาษา (INPUT/OUTPUT_LANGUAGE), กฎเหล็ก, และ output 8 ส่วน

### ขั้นที่ 2 · เลือกชุดที่เหมาะกับสินค้า
- ดู `index.csv` → เรียงตาม `niche_th` หรือ `angle_th` ได้เลย
- ถ้าเปิดด้วย Sheets: ใช้ Filter หรือทำ dropdown เลือก `id` แล้วดึง `prompt_th`
- ทางลัด: สินค้ามีปัญหาชัดเจน → **Problem–Solution (มุม 1)** · มีของจริงอยู่ในมือ → **Unboxing (3)** หรือ **สาธิต (4)** · คนถามเยอะ → **ตอบคอมเมนต์ (7)**

### ขั้นที่ 3 · เติมตัวแปร (สำคัญที่สุด)
ตัวแปรทุกตัวมีคำอธิบายใน `README.md` → พจนานุกรมตัวแปร / full glossary in README.

| ตัวแปร | เติมอย่างไร |
|---|---|
| `[INPUT_LANGUAGE]` | ภาษาของข้อมูลสินค้าที่คุณป้อน (ไทย / English) |
| `[OUTPUT_LANGUAGE]` | ภาษาคำตอบ (ไทย / ไทย+อังกฤษ / English) |
| `[สินค้า]` | ชื่อ + รุ่น/สี/ขนาด ตามหน้าสินค้าจริง |
| `[จุดเด่น 1-2 อย่าง]` | เฉพาะที่พิสูจน์ได้จากหน้าสินค้า/ฉลาก — **ห้ามเดา** |
| `[ราคา/โปร]` | ตัวเลขที่ตรวจแล้วและยังใช้ได้จริง |
| `[ประสบการณ์จริง]` | สิ่งที่คุณลองเองจริง ๆ ถ้าไม่มี ให้เขียน "ยังไม่ได้ทดสอบ" |
| `[กลุ่มเป้าหมาย]` `[ความยาวคลิป]` `[โทน]` | ใครดู / กี่วินาที / น้ำเสียง |

> ⚠️ อย่าป้อนข้อมูลที่ยังไม่ยืนยัน — ให้ AI ตั้งธง "ต้องตรวจสอบ" แทนการเดา
> ⚠️ Never feed unverified data — the AI should flag it instead of guessing.

### ขั้นที่ 4 · สั่งและอ่านคำตอบ 8 ส่วน
คำตอบที่ดีต้องครบทั้ง 8: 1 แนวคิด+ความยาว · 2 Hook 3 แบบ · 3 Shot list มีวินาที · 4 จุดเด่น ≤2 · 5 CTA ตะกร้า · 6 แคปชัน+แฮชแท็ก · 7 Disclosure · 8 ⚠️ เช็คลิสต์
ขาดส่วนไหน → พิมพ์ "ตอบครบทั้ง 8 ส่วนตาม SYSTEM PROMPT"

### ขั้นที่ 5 · ตรวจก่อนโพสต์ (เช็กลิสต์สั้น)
- [ ] เปิด **Commercial Content Disclosure** ในแอป TikTok
- [ ] พูดประโยคเปิดเผยในคลิป + ใส่ในแคปชัน (ไม่ใช่แค่แฮชแท็ก)
- [ ] ราคา/โปร/สเปก/เลข อย. ตรงของจริงทุกตัว
- [ ] ไม่มีคำว่า รักษา/หาย/ปลอดภัย 100%/รับประกันผล/ลดน้ำหนักใน X วัน
- [ ] อาหารเสริม: ไม่มีภาพก่อน–หลัง · มีคำเตือนตามฉลาก
- [ ] ยืนยันอัตราคอมมิชชันจริงที่หน้าสินค้า (Product Marketplace)

## 4. ตัวอย่าง 3 แบบ / 3 examples

ทั้ง 3 ไฟล์อยู่ใน `examples/` เป็น "หน้าตาคำตอบที่ควรได้" ครบทั้ง 8 ส่วน (สินค้าสมมติ — ห้ามคัดลอกข้อเท็จจริงไปใช้จริง)
All three files in `examples/` show what a good answer looks like (fictional products — never copy the facts).

| # | ไฟล์ | ชุด · หมวด | สอนอะไร / What it demonstrates |
|---|---|---|---|
| ตัวอย่างที่ 1 | `examples/001-full-example-skincare.md` | **001** Problem–Solution · สกินแคร์ | เคสพื้นฐาน — OUTPUT ไทย+อังกฤษ, Hook 3 แบบ, shot list วินาทีต่อวินาที, disclosure ครบ |
| ตัวอย่างที่ 2 | `examples/002-full-example-supplements.md` | **047** Problem–Solution · อาหารเสริม ⚠️ | เคสความเสี่ยงสูง — ยังขายได้โดยไม่ผิดกฎ: ไม่อ้างโรค, ไม่ before–after, ใส่คำเตือน+คำปรึกษาแพทย์ |
| ตัวอย่างที่ 3 | `examples/003-full-example-gadget.md` | **139** Problem–Solution · แกดเจ็ต | เคส OUTPUT = English ล้วน — อ้างสเปกอย่างเดียว, บอกชัดว่าส่วนไหน "ยังไม่ได้ทดสอบ" |

**ตัวอย่างสั้น ๆ จากทั้ง 3 / Quick peek:**

- **ที่ 1 (สกินแคร์):** Hook — *"ผิวแห้งจนแต่งหน้าไม่ติด ใครเป็นแบบนี้บ้าง 🙋‍♀️"* → สาธิตเนื้อสัมผัสจริง → *"เปิดตะกร้าเหลือง 👉"*
- **ที่ 2 (อาหารเสริม):** Hook — *"วันไหนกินผักน้อย เราจะเสริมด้วยตัวนี้ (ไม่ใช่ยา) 🥬"* → โชว์ฉลาก/เลข อย. → CTA + คำเตือนและประโยคเปิดเผย
- **ที่ 3 (แกดเจ็ต):** Hook (EN) — *"Cable mess on my desk again? Fixed it in 30 seconds."* → demo ของจริง → *"Full specs are in the yellow cart — I haven't tested X yet."*

**วิธีใช้ตัวอย่าง:** เปิดไฟล์คู่กับคำตอบที่ AI ของคุณเพิ่งให้ → ไล่เทียบทีละหัวข้อ 8 ข้อ → ตรงไหนขาด/อ่อนกว่า สั่ง AI แก้เฉพาะส่วนนั้น
**How to use:** open the file next to your AI's answer → compare section by section → ask the AI to revise only the weak sections.

## 5. แก้ปัญหาที่พบบ่อย / Troubleshooting

| ปัญหา | วิธีแก้ / Fix |
|---|---|
| คำตอบไม่ครบ 8 ส่วน | พิมพ์: "ตอบครบทั้ง 8 ส่วนตาม SYSTEM PROMPT" |
| ภาษาคำตอบไม่ตรง | ตั้ง `[OUTPUT_LANGUAGE]` ใหม่ใน prompt แล้วสั่ง "เขียนใหม่ทั้งหมดเป็น [ภาษา]" |
| AI เดาข้อมูล/ใส่ตัวเลขเอง | พิมพ์ "เอาเฉพาะข้อมูลที่ฉันให้ ส่วนที่ขาดให้ตั้งธง ⚠️ ต้องตรวจสอบ" |
| Hook ซ้ำ/ไม่น่าดู | รันชุดเดิมซ้ำโดยเพิ่ม "เปลี่ยน hook อีก 3 แบบ ไม่ใช้แบบเดิม" หรือสลับมุม (ชุดอื่นในหมวดเดียวกัน) |
| คำตอบยาว/สั้นเกินไป | ระบุ `[ความยาวคลิป]` ชัดเจน เช่น "25–30 วินาที" แล้วสั่ง "ปรับ shot list ให้ตรง 25 วิ" |
| อยากได้หลายหมวดพร้อมกัน | เปิด 1 แชทต่อ 1 สินค้า หรือใช้ `prompts-599.csv` แล้ววนชุดใน Sheets |
| ข้อมูลสินค้าเป็นภาษาอังกฤษ แต่ต้องการผลลัพธ์เป็นไทย | `[INPUT_LANGUAGE]=English` + `[OUTPUT_LANGUAGE]=ไทย` |

### 6.3 การรับเวอร์ชันใหม่ / How you get updates (อัตโนมัติ)
**ซื้อครั้งเดียว — เวอร์ชันใหม่เป็นของคุณฟรีทุกครั้ง ไม่มีค่าสมาชิก/ต่ออายุ**

1. **ไม่ต้องสมัครอะไรเพิ่ม** — เราเก็บอีเมลที่คุณใช้ซื้อไว้ และเมื่อมีเวอร์ชันใหม่ ระบบจะส่ง **อีเมลแจ้ง + ลิงก์ดาวน์โหลด** ให้เอง
   (หัวเรื่องจะบอกเลขเวอร์ชัน เช่น “มีเวอร์ชันใหม่ v1.5” ดูเพิ่มได้ที่ <https://kopwang.com/retrieve> ตอนขอลิงก์ใหม่)
2. **ลิงก์เก่าของคุณก็ได้ไฟล์ใหม่** — ลิงก์ในอีเมลเก่า (หรือปุ่มดาวน์โหลดบนหน้าเว็บ) โหลด **ไฟล์รุ่นล่าสุดเสมอ** ไม่ต้องรอลิงก์ใหม่
   ลิงก์ในอีเมลแจ้งรุ่นใหม่มีอายุ **30 วัน** และโหลดซ้ำได้ไม่จำกัด · ถ้าหมดอายุก็ขอลิงก์ใหม่ได้ที่หน้า `/retrieve`
3. **เช็คว่าคุณได้รุ่นไหน** — บนหน้าปกในไฟล์ PDF มีบรรทัด `เวอร์ชัน …` และชื่อไฟล์ที่ดาวน์โหลดมีเลขรุ่นต่อท้าย (เช่น `…-v1.5.pdf`)
4. ดาวน์โหลดแล้ว **แตกไฟล์ทับโฟลเดอร์เดิม** — ไฟล์ `prompts/` และ `examples/` ถูกแทนที่ ส่วนไฟล์งานของคุณใน Sheets ไม่หาย
5. **ไม่ต้องการรับอีเมลแจ้งรุ่นใหม่?** กด “ยกเลิกรับอีเมล” ท้ายอีเมลได้ทุกฉบับ (มีปุ่มยกเลิกในตัวสำหรับ Gmail/Outlook)
   — การยกเลิกจะหยุดแค่ *อีเมล* ส่วนการดาวน์โหลดไฟล์ที่ซื้อแล้วยังใช้ได้ตามปกติ
4. ตรวจช่อง **ประวัติเวอร์ชัน (6.1)** ว่าตรงกับไฟล์ที่ดาวน์โหลดล่าสุดหรือไม่

### 6.4 แจ้งเรื่องที่ขอได้ / What you can request
- หมวดสินค้าใหม่ / new niche หรือมุมคอนเทนต์ใหม่ / new angle

- แปลแพ็กเป็นภาษาอื่น / ขอเวอร์ชัน CSV ที่ปรับคอลัมน์
- รายงานข้อผิดพลาดหรือ prompt ที่ใช้แล้วผลไม่ได้
