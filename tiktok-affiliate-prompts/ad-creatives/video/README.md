## โซนปลอดภัยที่กันไว้

กันขอบซ้าย 70px · ขวา 100px (คอลัมน์ปุ่มไลก์/แชร์/คอมเมนต์ของ TikTok) · บน 180px (แถบสถานะ) · ล่าง 320px (แคปชัน + UI)
สคริปต์เรนเดอร์จะ **ฟ้องทันที** ถ้าข้อความไหนล้นกรอบตัวเอง หรือหลุดโซนนี้

## เรนเดอร์ซ้ำ / แก้ข้อความ

```bash
# ต้องใช้ python ของ shop/.venv (มี playwright + imageio-ffmpeg) และ Chromium ที่ playwright ติดตั้งไว้
# ⚙️ ในกล่องที่ไม่มีไลบรารี/ฟอนต์ของระบบ ให้โหลด env ก่อน (ชี้ LD_LIBRARY_PATH + fonts.conf ที่ .scratch/fonts ซึ่งมี Kanit · Sarabun · Noto Color Emoji)
source .scratch/render-env.sh          # รันจากรูท repo

# ดูตัวอย่างเฉพาะบางเวลา (เร็ว) → .scratch/reel-preview/
shop/.venv/bin/python ad-creatives/video/render_reel.py --preview 1.5,3.6,6.5,7.9

# เรนเดอร์เต็ม → ad-creatives/video/out/reel-basket.mp4 + cover.png
shop/.venv/bin/python ad-creatives/video/render_reel.py

# เรนเดอร์ฮุกอื่นจากเทมเพลตเดียวกัน (ไม่ต้องแก้ HTML) — 1 บรรทัด = 1 บรรทัดบนจอ (สูงสุด 3)
shop/.venv/bin/python ad-creatives/video/render_reel.py --hook "ปักตะกร้าแล้ว|แต่ยอดวิวไม่ขึ้น?" --out reel-hook2.mp4
shop/.venv/bin/python ad-creatives/video/render_reel.py --hook "อยากขายของใน TikTok|ไม่ต้องเป็นนักเขียนก็ได้" --out reel-hook3.mp4
```

แก้ข้อความได้ใน `reel-basket.html` หรือใช้ `--hook` แทน (เหมาะกับทำหลายมุมจากเทมเพลตเดียว — เสียง/ซีนที่เหลือไม่เปลี่ยน) แล้วเรนเดอร์ใหม่ — เสียงจะถูกสร้างใหม่ทุกครั้ง

### ค่าที่เพิ่มเมื่อ 18 ต.ค. 2026

- `--hook "บรรทัด1|บรรทัด2|บรรทัด3"` — เขียนทับข้อความฮุกในซีนแรก (`#l1`–`#l3`) · บรรทัดที่เว้นว่างจะถูกซ่อน ไม่ทิ้งช่องว่าง · สคริปต์ **ตรวจซ้ำว่าฮุกใหม่ขึ้นบนหน้าจริง** ก่อนเรนเดอร์ (ถ้าไม่ขึ้น = หยุดพร้อมบอกสาเหตุ)
- `--out <ชื่อไฟล์>` · `--cover <ชื่อไฟล์>` — เลือกชื่อไฟล์ผลลัพธ์/ปกในโฟลเดอร์ `out/`
- 🐛 **แก้บั๊กตรวจข้อความค้างรุ่นเก่า:** `REQUIRED_TEXT` เดิมบังคับคำว่า `100 Prompt` (ชื่อแพ็กเก่า) ทั้งที่สินค้าเปลี่ยนเป็น 599 แล้ว ⇒ ทุกรอบเรนเดอร์จะ "ข้อความขาด" แล้วหยุดโดยไม่ได้ไฟล์ · แก้เป็น `599 Prompt` และเพิ่มการตรวจบรรทัด compliance เต็ม ๆ (`ผลลัพธ์ขึ้นกับสินค้าและคอนเทนต์ของคุณ`)
- 🐛 **แก้ด่านตรวจข้อความให้อ่าน "บนจอ" จริง:** แต่ก่อนอ่าน `inner_text` ครั้งเดียวตอนโหลดเพจ — ซึ่งยังไม่เรียก `renderAt()` (สคริปต์ตั้ง `__NO_AUTOPLAY__`) จอจึงว่างเปล่าและขึ้น "ข้อความขาด" ทั้งหมด · ตอนนี้สุ่มอ่าน 8 ช่วงเวลา (`DEFAULT_SAMPLE_TIMES`) แล้ว **ถ้าจอว่างทุกช่วง = หยุดพร้อมบอกว่าเครื่องไม่มีฟอนต์ติดตั้ง** (กล่องข้อความจะสูง 0 ⇒ คลิปที่เรนเดอร์ออกมาจะไม่มีตัวหนังสือ) — แก้ครั้งนี้ตรวจเจอจริงในกล่องที่ถูก restore แล้วฟอนต์หายก่อน จึงไม่ปล่อยคลิปเปล่าออกไป
- ⚙️ **ต้องมีฟอนต์ในเครื่องก่อนเรนเดอร์:** Kanit · Sarabun · Noto Color Emoji (อีโมจิ 👉 ในปุ่ม CTA) · ถ้าไม่มี อีโมจิจะออกเป็นกล่องสี่เหลี่ยมหรือข้อความหาย — ดูวิธีติดตั้งใน `.scratch/render-env.sh`
