## โซนปลอดภัยที่กันไว้

กันขอบซ้าย 70px · ขวา 100px (คอลัมน์ปุ่มไลก์/แชร์/คอมเมนต์ของ TikTok) · บน 180px (แถบสถานะ) · ล่าง 320px (แคปชัน + UI)
สคริปต์เรนเดอร์จะ **ฟ้องทันที** ถ้าข้อความไหนล้นกรอบตัวเอง หรือหลุดโซนนี้

## เรนเดอร์ซ้ำ / แก้ข้อความ

```bash
# ต้องใช้ python ของ shop/.venv (มี playwright + imageio-ffmpeg) และ Chromium ที่ playwright ติดตั้งไว้
export LD_LIBRARY_PATH=<workspace>/.scratch/debs/root/usr/lib/x86_64-linux-gnu
export FONTCONFIG_FILE=<workspace>/.scratch/fonts.conf

# ดูตัวอย่างเฉพาะบางเวลา (เร็ว) → .scratch/reel-preview/
shop/.venv/bin/python ad-creatives/video/render_reel.py --preview 1.5,3.6,6.5,7.9

# เรนเดอร์เต็ม → ad-creatives/video/out/reel-basket.mp4 + cover.png
shop/.venv/bin/python ad-creatives/video/render_reel.py
```

แก้ข้อความได้ใน `reel-basket.html` (หรือเปลี่ยนฮุกตาม `CAPTION.md` ข้อ 3) แล้วเรนเดอร์ใหม่ — เสียงจะถูกสร้างใหม่ทุกครั้ง
