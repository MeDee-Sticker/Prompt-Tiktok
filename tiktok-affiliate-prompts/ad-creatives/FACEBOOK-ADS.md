- **Budget:** `฿100/วัน` แบบ Daily · ไม่ตั้งวันสิ้นสุด → **ปิดหลัง 3 วัน (ใช้จ่ายรวม ฿300)**
- **Ad set:** ประเทศไทย · อายุ 25–45 · ทุกเพศ · ภาษา: ไทย (ถ้ามีตัวเลือก) · **Advantage audience เปิด** และช่อง Detailed targeting ใส่: `TikTok`, `TikTok Shop`, `affiliate marketing`, `e-commerce`, `online shopping`, `small business` — เลือกตัวที่มีผู้ใช้ 1 ล้าน+ (ชื่อความสนใจใน Meta เปลี่ยนบ่อย พิมพ์แล้วเลือกจากรายการที่ระบบเสนอเสมอ)
- **Placements:** `Manual` → เปิด **Facebook Feed, Facebook Reels, Instagram Feed, Instagram Reels, Stories** · **ปิด Audience Network** (คลิกห่วยและหลอกคุณภาพ)
- **Ads:** 4 ชิ้น — ภาพ 3 + คลิป 1 (ข้อความ A1/A2/A3 + คลิปใช้ A1)

### C2 · เก็บอีเมล — เปิดวันที่ 2 (งบ ฿100/วัน)

### C3 · รีมาร์เก็ตติ้ง — เปิดหลังมีคนกดลิงก์ ≥ 300 คน
- Ad set ใช้ **Custom Audience จาก Engagement** (กลุ่มนี้**ไม่ต้องมี Pixel** ก็สร้างได้): `คนที่ดูวิดีโอ 50% ขึ้นไป (7 วัน)` · `คนที่กดหรือมีส่วนร่วมกับเพจ/IG (365 วัน)` · `คนที่เปิดฟอร์ม` — สร้างที่ Events Manager → Audiences → Create → Custom Audience → Engagement
- ⚠️ กลุ่ม `คนที่เข้าหน้าเว็บ/กดลิงก์บนเว็บ` **ต้องมี Pixel ก่อน** จึงจะสร้างได้ (ถ้าอยากได้กลุ่มนี้ ต้องทำข้อ 0.3 ให้จบ)

**กติกาปิด/ปรับ (เขียนไว้เลย):** ครบ 3 วันแล้วดู — CTR < 1% → เปลี่ยนภาพ/หัวข้อ · CPC > ฿10 → ลดงบหรือเปลี่ยนกลุ่ม · มีคนกด > 100 แต่ไม่มีออเดอร์เลย → **หยุดยิง แล้วแก้ขั้นตอนจ่ายเงินก่อน** (ไม่ใช่เพิ่มงบ)

## 9) กดยิงจริง — ลำดับคลิกใน Ads Manager

1. `adsmanager.facebook.com` → **Create** → Objective **Traffic** → Continue
2. ตั้งชื่อแคมเปญ `pp99-c1-traffic` · ปิด A/B test · งบระดับ Ad set
3. Ad set: ชื่อ `broad-25-45` · Conversion location `Website` · Performance goal `Landing page views` · งบ `฿100/วัน` · กลุ่มเป้าหมายประเทศไทย อายุ 25–45 (ข้อ 6) · Placements Manual (ปิด Audience Network)
4. Ad: ตั้งชื่อ `ad-classic` · เลือกเพจ + IG · รูปแบบ `Single image or video` · อัปโหลดภาพ `ad-01-classic.png`
5. Primary text / Headline / Description / Website URL = จากข้อ 5 และข้อ 3 (ใส่ UTM ให้ครบ)
6. กด **Preview** → เช็กบนมือถือจริง: ลิงก์กดได้ · หน้าซื้อโหลดไว · QR ขึ้น
7. **Publish** → รอสถานะ `In review` (ปกติ 1–24 ชม. · ครั้งแรกอาจถึง 24 ชม.)
8. ยิงเสร็จทันทีหลัง Publish: ทดสอบซื้อเอง 1 ออเดอร์ (จ่าย ฿99 เข้าบัญชีตัวเอง) เพื่อดูว่าลูกค้าเห็นอะไรจริง ๆ ในขั้นตอนดาวน์โหลด
