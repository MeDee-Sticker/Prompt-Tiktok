# CAPTIONS.md — แคปชัน + แฮชแท็กสำหรับโฆษณา TikTok 3 แบบ

คู่กับ `ad-01-classic.html` · `ad-02-dark.html` · `ad-03-meme.html` (แคปที่ 1080×1350)
ทุกแคปชันใช้ **ชื่อสินค้า “599 Prompt ก๊อปวาง”** และ **คำโปรยชุดเดียวกับที่อยู่ในภาพ + ปกหน้า PDF v1.3**
ก๊อปจากบล็อกด้านล่างไปวางเป็นแคปชันโพสต์ได้เลย (ไม่ต้องแก้อะไร)

## โครงแคปชันที่ใช้ทั้ง 3 โพสต์
1. **Hook 1–2 บรรทัดแรก** — ต้องจบใน 1 บรรทัด เพราะ TikTok ตัดเป็น “เพิ่มเติม…” หลังจากนั้น
2. คำโปรยชุดเดียวกับภาพ → `ชุดเดียวจบ · ก๊อปไปวาง ได้สคริปต์พร้อมถ่าย` + `ไม่ต้องเป็นนักเขียน ไม่ต้องมีไอเดียใหม่ และไม่ต้องเก่งอังกฤษ`
3. สิ่งที่ได้ในชุด (26 หมวดขายดี × 23 มุม · สองภาษา TH/EN)
4. ราคา `999฿ → 99 บาท` + ดาวน์โหลดทันทีหลังชำระ
5. **CTA ให้ตรงกับปุ่มที่อยู่ในภาพ** (ตะกร้า / ปุ่ม “ดูรายละเอียด”)
6. เปิดเผยว่ามีค่าคอมมิชชัน + ไม่ใช่การรับประกันรายได้
7. แฮชแท็ก 6–7 ตัว

> ⚠️ อย่าใส่ URL ในแคปชัน — ลิงก์ซื้อให้ผูกที่ **ตะกร้า TikTok Shop** ของโพสต์นั้น
> ⚠️ ทั้ง 3 โพสต์ใช้ “คำโปรยชุดเดียวกัน” แต่**เปลี่ยน Hook/มุมเล่า** ให้ต่างกัน — ห้ามโพสต์ข้อความเหมือนกันเป๊ะ ๆ ทั้ง 3 ครั้ง (TikTok มองว่าเป็นสแปม)
> ℹ️ ภาพแบบที่ 1 ไม่มีบรรทัด “ไม่ใช่การรับประกันรายได้” (แบบที่ 2–3 มี) — แคปชันของโพสต์ที่ 1 จึงใส่ข้อความนี้ไว้ให้ครบ

## วิธีใช้
1. เปิด `index.html` → เปิดแต่ละแบบเต็มหน้าแล้วแคป/ส่งออกภาพที่ 1080×1350 (สเกล 100% · ไม่ต้องซูมเข้า/ออก)
2. ก๊อปแคปชันของโพสต์นั้นจากบล็อกด้านบน → วางในช่องแคปชัน TikTok
3. ผูกลิงก์สินค้าที่ **ตะกร้า** (TikTok Shop) แล้วตรวจว่าปุ่มที่ลูกค้าเห็นตรงกับ CTA ในแคปชัน
4. ปักคอมเมนต์ด้านบนไว้เป็นคอมเมนต์แรก
5. เช็ก 3 ข้อก่อนกดโพสต์: ชื่อ “599 Prompt ก๊อปวาง” · คำโปรย “ชุดเดียวจบ · ก๊อปไปวาง ได้สคริปต์พร้อมถ่าย” · มีข้อความเปิดเผยค่าคอมมิชชัน

*ข้อความราคา/โปรโมชันในแคปชันต้องตรงกับหน้าเว็บขาย (฿99) ทุกครั้งที่มีการเปลี่ยนราคา*
