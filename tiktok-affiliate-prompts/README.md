## วิธีใช้ / How to use

1. เปิด `00_master-template.md` → คัดลอก **SYSTEM PROMPT** ไปวางเป็น system message ของ AI (ทำครั้งเดียว)
   Open `00_master-template.md` and paste the **SYSTEM PROMPT** as the AI's system message (once).
2. เลือกชุดจาก `index.csv` → เปิดไฟล์ใน `prompts/` → คัดลอก **PROMPT** ของชุดนั้นไปวางเป็น user message
   Pick a set from `index.csv`, open its file in `prompts/`, and paste that set's **PROMPT** as the user message.
3. เติมตัวแปรในวงเล็บให้ครบ แล้วสั่ง AI ให้เขียนสคริปต์
   Fill the bracketed variables, then ask the AI to write the script.

ทุกชุดมี 2 เวอร์ชัน: **PROMPT (TH)** และ **PROMPT (EN)** ใช้อย่างใดอย่างหนึ่งได้
Each set ships in **PROMPT (TH)** and **PROMPT (EN)** — use either one.

## พจนานุกรมตัวแปร / Variable glossary

| ตัวแปร / Variable | ความหมาย / Meaning |
|---|---|
| `[INPUT_LANGUAGE]` | ภาษาของข้อมูลสินค้าที่ป้อนให้ AI (เช่น ไทย / อังกฤษ) — ระบุเพื่อให้ AI อ่านข้อมูลนำเข้าถูกภาษา<br>Language of the source product info you feed the AI (e.g. Thai / English) |
| `[OUTPUT_LANGUAGE]` | ภาษาที่ต้องการให้ AI เขียนผลลัพธ์ (เช่น ไทย / ไทย+อังกฤษ)<br>Language you want the output written in (e.g. Thai / Thai+English) |
| `[สินค้า]` / `[PRODUCT]` | ชื่อสินค้า + รุ่น/สี/ขนาด<br>Product name + variant/color/size |

| `[โทน]` / `[TONE]` | น้ำเสียง เช่น จริงใจ/ตลก/เพื่อนแนะนำเพื่อน<br>Tone, e.g. sincere / funny / friend-to-friend |

## กฎความปลอดภัยที่ฝังในทุกชุด / Compliance rules embedded in every set

- **เปิดเผย Affiliate ทุกคลิป:** เปิด Commercial Content Disclosure ในแอปทุกครั้งที่มีค่าคอมมิชชัน, พูดออกเสียงในคลิป, และใส่ในแคปชัน — แฮชแท็กอย่างเดียวไม่นับ
  **Disclose every time:** turn on the in-app Commercial Content Disclosure whenever you earn a commission, say it aloud in the video, and put it in the caption. Hashtags alone are not enough.
- **ห้ามกล่าวอ้างเกินจริง:** ห้ามอ้างว่ารักษา/บรรเทา/ป้องกันโรค, ห้าม "ปลอดภัย 100%", ห้าม "ลดน้ำหนักใน X วัน", ห้ามรับประกันรายได้
  **No false claims:** no cure/treat/prevent disease, no "100% safe", no "lose weight in X days", no income guarantees.
- **อาหารเสริม/เครื่องสำอาง (ไทย):** ยึดแนวทาง อย. — ห้ามใช้ภาพก่อน–หลังกับอาหารเสริม, ข้อมูลต้องตรงฉลาก
  **Supplements/cosmetics (Thailand):** follow FDA (อย.) guidance — no before/after for supplements; info must match the label.
- **รีวิวตามจริง:** ใช้ภาพของจริง ไม่ตัดต่อให้ผลลัพธ์ดูต่าง, ถ้าข้อมูลขาดให้ AI "ตั้งธงถาม" ไม่ให้เดา
  **Truthful demo:** real footage, no altered results; if data is missing, the AI must flag it instead of guessing.
- **เช็กอัตราคอมมิชชัน:** ดูเรตจริงที่หน้าสินค้าใน Product Marketplace (อย่าใช้ตัวเลขเหมารวม)
  **Check commission:** verify the real rate on the product page in Product Marketplace (don't trust generic averages).

> ที่มา/อ้างอิงหลัก: TikTok Commercial Content Disclosure, TikTok Shop Content Policy, TikTok Creative Best Practices, แนวทางโฆษณา อย. (ไทย), FTC Disclosure Guides

## ใช้กับ Google Sheets / Excel

1. เปิด Google Sheets → **File → Import → Upload** → เลือก `prompts-599.csv`
   (ไฟล์เป็น UTF-8 BOM ภาษาไทยจะไม่เพี้ยน) หรือเปิดด้วย Excel ได้เลย
2. แต่ละแถว = 1 ชุด มีคอลัมน์: `id, niche_th, niche_en, angle_th, angle_en, title, file, prompt_th, prompt_en, example_*`
3. คัดลอกคอลัมน์ `prompt_th` หรือ `prompt_en` ไปวางใน AI ได้ทันที — หรือทำเป็น dropdown เลือกชุด
4. `index.csv` เป็นเวอร์ชันเบา (เฉพาะ metadata) ถ้าไม่ต้องการคอลัมน์ prompt ยาว ๆ
