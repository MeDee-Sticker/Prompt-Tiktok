## 1) กติกาวัดผล: ทุกโพสต์ต้องมี `src`

วันนี้หน้า `/` และ `/order` อ่าน `?src=` หรือ `utm_source`+`utm_campaign` แล้วเก็บลงออเดอร์ (`orders.src`) → หลังบ้าน `/admin` มีคอลัมน์ **ที่มา** + สรุป **“ช่องทางที่มา”** (paid/ทั้งหมด + รายได้ต่อช่องทาง)
**ไม่มี Pixel ก็ตอบได้ว่าโพสต์ไหนพาคนซื้อ** — แต่ต้องมีวินัย: 1 ช่องทาง = 1 `src` ห้ามใช้ซ้ำ

| ช่องทาง | ลิงก์ที่ใช้ (ก๊อปวาง) | `src` ที่จะเห็นในหลังบ้าน |
|---|---|---|
| ไบโอ TikTok | `https://kopwang.com/links?src=tiktok` | `tiktok` |
| คอมเมนต์ปักหมุด TikTok | `https://kopwang.com/free?src=tiktok-cm` | `tiktok-cm` |
| โพสต์เพจ Facebook | `https://kopwang.com/?src=fb-post-n` | `fb-post-1` … (โพสต์ 1–3 ลงแล้ว 18 ต.ค. 2026 · ดู `ad-creatives/CAPTIONS.md`) |
| คลิป Reels (คลิปที่ n) | `https://kopwang.com/?src=fbreel-0n` | `fbreel-01` … |
| กลุ่ม Facebook (ชื่อกลุ่มย่อ) | `https://kopwang.com/free?src=fbgroup-<ชื่อย่อ>` | `fbgroup-…` |
| ดีเอ็ม/แชตส่วนตัว | `https://kopwang.com/?src=dm` | `dm` |
| อีเมลถึงคนที่กรอก `/free` | `https://kopwang.com/?src=email-01` | `email-01` |
| ครีเอเตอร์ที่รีวิวให้ | `https://kopwang.com/free?src=creator-<ชื่อ>` | `creator-…` |
| แอด Facebook (ตาราง UTM เดิม) | ใช้ลิงก์ใน `FACEBOOK-ADS.md` §3 ได้เลย | `facebook` (จาก `utm_source`) |

> หมายเหตุ: `src` ถูกจำไว้ในแท็บ (sessionStorage) — คนที่เข้าหน้าแรกแล้วไปต่อ `/free` หรือ `/30day` จะยังนับช่องทางเดิม

## 4) กติกาปิด/ปรับ (เหมือน `FACEBOOK-ADS.md` §7)

- มีคนกด ≥ 100 แต่ **0 ออเดอร์** → หยุดยิง แล้วแก้ขั้นตอนจ่ายเงิน/ราคา (อย่าเพิ่มงบ)
- CTR < 1% (แอด) → เปลี่ยนภาพ/หัวข้อ ไม่ใช่เพิ่มงบ
- CPC > ฿10 → ลดงบหรือเปลี่ยนกลุ่ม
- lead เยอะแต่ paid = 0 → ปัญหาอยู่ที่หน้า `/` หรือราคา ไม่ใช่ทราฟฟิก
- ช่องทางไหนได้ paid ≥ 2 → ทำซ้ำช่องทางนั้นก่อน อย่าเปิดช่องใหม่
